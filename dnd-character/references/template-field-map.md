# 5R 模板字段映射（用户提供的悲灵／弗人／枭熊适配版）

“可写”只表示脚本可写输入格；公式格必须由 WPS／Excel 重算。更换模板版本时，先重新核对地址和公式依赖。以下地址均为本项目 `assets/dnd5r-blank.xlsx` 的实测映射。

| 页签与格位 | 用途 | 可写 | 查询／计算依赖 |
| --- | --- | --- | --- |
| `主要!E6`、`I6` | 主职业、子职显示 | 是 | 卡面显示；**不能代替职业能力查询键** |
| `主要!AW9`、`BD9` | 主职业、子职的职业能力查询键 | 是 | `职业!AK2`、`CN2`、`CN3` 读取它们；进一步驱动职业特性名称、等级、描述等查找。须与 `E6`、`I6` 一致。 |
| `主要!AW17:AW64` | 职业能力等级 | 否 | `职业!CV8` 起的查找公式；不要把“1级”附在能力名称里。 |
| `主要!AX17:AX64`、`BC17:BC64` | 职业／子职特性原名、卡面简述 | 是 | `AX` 名称必须来自模板 `职业` 数据表，按取得等级升序；不得放法术效果、战术建议、建卡备注。`BC` 只放能读完的短说明，全文放战斗速查。 |
| `主要!BT19:BT29`、`BU19:BU29`、`BZ19:BZ29` | 专长取得等级、原名、短说明 | 是 | `BT` 有模板默认等级，必须逐项覆盖；来源在计划与速查中保留。 |
| `主要!Q66:Q73` | 无消耗法术名称 | 是 | 只列**不在准备区**的免费法术；同名已准备法术只列一次，免费次数另记资源格。 |
| `主要!Y66:Y73`、`AG66:AG74`、`AO66:AO74` | 准备法术名称 | 是 | 合并自选与额外常备，按环阶升序、同环连续、每列自上而下排列；来源在计划与速查中保留。 |
| `主要!Q77:Q80`、`Y77:Y80` | 戏法 | 是 | 来自 `cantrips`；与准备法术分区。 |
| `主要!E72:E80` | 当前各环法术位 | 是 | 最大值在 `H72:H80` 由职业表公式求得；保存后须核对剩余值未超过上限。 |
| `主要!B26:O28` | 有限次数资源 | 是 | 名称、当前、最大、恢复方式；含有限次数免费施法。 |
| `主要!G22`、`G23`、`BB7` | 额外先攻、额外 AC、固定 HP 加值 | 是 | `D22`、`D23`、`BF7→V22`；例如警觉、防御、健壮的文字说明不能替代这些数值输入。 |
| `主要!L40`、`AP40`、`AS40` | 具体护甲名、盾牌名、是否装备 | 是 | `D23` 的 AC 公式读取护甲和盾牌状态。`L40` 填“链甲”等名称，不填“重甲”类别。 |
| `主要!AI59`、`AP59`、`AI60:AI62` | GP、PP、EP、SP、CP | 是 | 钱币与负重相关公式；零也要明确填写。 |
| `背包!B5:B14` | 左侧冒险装备速查 | 否（本脚本） | 不是实际携带清单，写在这里不会把数量／重量送进背包计重。 |
| `背包!Y5:Y14`、`Y16:Y25`；`AP`、`AS` 同行 | 背包 1：物品、单件磅重、数量 | 是 | `装备!E14` 等按重量×数量计重；`主要!P60` 链接背包总重。 |
| `背包!B29:B38`、`B40:B49`；`S`、`V` 同行 | 背包 2：物品、单件磅重、数量 | 是 | `装备!F14` 等计重；`主要!T60` 链接背包总重。 |
| `主要!AK30`、`AS30` | 一种弹药名称、数量 | 是 | 由主卡弹药区计重；不要在背包再计同一批。 |
| `主要!D22`、`D23`、`V22` | 重算后的先攻、AC、HP | 否 | 原生重算、保存、关闭后重新读取；与 `level_audit.expected_totals` 对照。`AW17` 起的职业能力等级缓存也须逐项核对。 |

样卡“阿格蕾”只用于观察条目顺序、法术纵向排列和熟练信息位置。不得复制其职业数据、专长等级或未取得的高等级特性。
