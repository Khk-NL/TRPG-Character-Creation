# 规则口径与来源

先看 DM 明确允许的版本和书籍，再查对应规则。用户指定的[灰机百科规则速查](https://dnd.huijiwiki.com/wiki/%E8%A7%84%E5%88%99%E9%80%9F%E6%9F%A5#5E%E8%A7%84%E5%88%99%E9%80%9F%E6%9F%A5)是 5E 速查入口，不等于 2024 修订规则。当前环境打开该网页返回访问错误，因此规则分界以官方 Basic Rules 与用户提供的 CHM 两套章节交叉核对；使用时仍应尽量重新访问玩家指定页面。

| 项目 | 5E / 2014 | 5R / 2024 |
|---|---|---|
| 核心建卡顺序 | 种族、职业、属性、背景等 | 职业、起源（背景/种族/语言）、属性等 |
| 一级属性加值 | 由种族/亚种等来源提供 | 由背景给出的三项属性中分配 +2/+1 或三项 +1 |
| 背景 | 两项技能、工具/语言及背景特性等，按条目 | 两项技能、一项工具、起源专长、属性候选、装备等 |
| 种族/物种 | 提供种族属性加值与特性 | 提供物种特性、体型、速度等；不重复加背景属性 |
| 一级专长 | 不因背景自动获得 2024 起源专长 | 背景给起源专长 |

官方原文：[2014 Basic Rules 建卡](https://www.dndbeyond.com/sources/dnd/basic-rules-2014/step-by-step-characters)、[2024 Basic Rules 建卡](https://www.dndbeyond.com/sources/dnd/br-2024/creating-a-character)、[2024 Character Origins](https://www.dndbeyond.com/sources/dnd/br-2024/character-origins)、[SRD 版本入口](https://www.dndbeyond.com/srd)。

用户提供了两份 CHM：`5E 不全书 天麟版v2023.01.31.chm` 可查 2014 版玩家手册的职业、种族与背景条目；`DND五版不全书26.09.13之吃吃艾拉斯卓浮空小脚.chm` 同时含 `玩家手册/`（2014）与 `玩家手册2024/`（2024）目录。先选版本，再查对应目录；CHM 中的扩展资料也须 DM 允许。CHM 不随 skill 发布。已填的阿格蕾表有 2024 起源专长和准备法术字段，只用来验证 5R 模板写入位置，不作为所有职业的默认样例。

人物卡模板只记录最终选择，不代替规则校验。职业命中骰、HP 增长、熟练项、子职等级、法术表、装备价格与武器性质，应在选定版本和允许的书籍中逐项核对，房规例外写在摘要中。
