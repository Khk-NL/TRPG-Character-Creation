# 魔法物品：核对、选择与落卡

仅在玩家询问魔法物品或本次新卡获准携带魔法物品时读取。不自动赠送魔法装备，不把“推荐A”当成玩家已选择或已经获得A；新增物品须有玩家选择及DM允许的来源、奖励或预算。

## 规则与状态

- 依角色已确定的规则版本查物品原文；核对准确名称、稀有度、基础武器/护甲类型、同调要求与限制、穿戴/持用条件、效果及使用资源。模板下拉选项不是规则依据。
- 在计划的附加说明或战斗速查逐件记录：来源、数量、位置、是否装备、是否需要同调、是否已同调、同调前提是否满足、当前启用的效果；同调数按实际已同调物品统计。通常上限3件，有明确职业例外时按该例外；不把所有魔法物品都当作需要同调。
- 需要同调但尚未同调、未满足穿戴/持用要求的物品，其相应魔法效果不能计入当前数值。同调不等于施法专注。
- 条件性效果保留触发条件。充能、每日次数、恢复时点和动作成本分别记录；物品自带施法不自动成为职业已知/准备法术，也不自动增加职业法术位。

## 计算与卡面

先算无该物品时的数值，再算启用后结果，并注明每个加值来源。比较物品时保持角色其他装备与状态相同，同时考虑AC、豁免、攻击/伤害、同调名额及持用要求。

本5R模板与脚本当前支持：

| 效果 | 输入与检查 |
| --- | --- |
| 额外AC，例如防护斗篷 | 加入 `combat.ac_bonus`，并在 `mechanical_effects` 列出来源；写入 `主要!G23`。穿着且完成同调时才计入斗篷效果。 |
| 六项豁免额外加值 | `combat.save_bonuses` 按STR/DEX/CON/INT/WIS/CHA记录，`save_bonuses_source` 写来源；写入 `主要!W13:W18`，不是修改熟练或基础属性。`level_audit.expected_save_totals` 写六项最终预期值，原生重算后核对 `T13:T18`。 |
| 普通盾／魔法盾 | `combat.shield.name` 写名称，`equipped` 写装备状态；`ac` 为这面盾提供的**总**AC，普通盾2、+1盾牌3。非2时须写 `ac_source`。分别落在 `AL40`、`AS40`、`AQ40`；`AP40` 是同调格，不能填名称。盾牌附魔加值已经包含在 `ac` 时，不再重复计入 `combat.ac_bonus`。 |
| 魔法武器的命中与伤害、其他物品效果 | 先核对该模板的武器加值与效果字段。当前脚本没有通用魔法物品自动识别；不凭名称猜测，也不在未支持的JSON字段中填值后声称已自动生效。需要人工补写时记录格位、效果与来源，逐项检查保存后的结果。 |

`save_bonuses` 未提供的属性按0处理；它表示所有来源合计的当前额外加值，不仅是某一件物品。移除或停用物品时要重新合计；不要清除其他物品、职业特性已有的加值。条件性优势/抗性不能直接换算成固定加值。法术DC或攻击加值不是伤害加值，普通盾与+1盾牌也不会自动提高伤害。

物品在装备栏与背包中只按实际数量计重。防护斗篷等未被脚本识别为 `equipped` 的物品，不伪装成武器或盾牌；使用实际携带清单并注明“已穿戴”，独立记录其启用效果。

## 两件常见物品的核对示例（不是默认装备）

- **防护斗篷**：穿着并完成同调时AC+1、所有豁免+1。六项豁免都要落实；规则提到的其他适用豁免也不能遗漏，按实际投骰规则处理。
- **+1盾牌**：不需要同调；持用时在普通盾+2之上再加1，因此该盾提供总AC+3。不是“总共只加1”，也不是在已有普通盾+2后再加3。
- 原本持普通盾的角色二选一：斗篷+普通盾，与换成+1盾牌，都是净AC+1；斗篷另给豁免加值但占同调名额。用实际角色的同调需求作选择，不写成任何时候都必选某件。

## 验收

检查物品的装备/同调状态、叠加来源和计重次数；原生重算、保存、关闭后重新读取实际文件，核对受影响的AC、六项豁免，以及适用的攻击、伤害和剩余资源。验卡说明区分脚本已核对的项目与人工检查项目。不为本次未选择的物品计入加值。
