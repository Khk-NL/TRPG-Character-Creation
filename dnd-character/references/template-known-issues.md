# DND 模板已知问题与验卡边界

- 用户实测：本机 Excel COM 未能打开原 5R 空白模板，原因尚未查明；WPS 可打开、重算并保存。不要把 COM 失败归因于角色计划，也不要声称已完成 Excel 原生验证。能用 WPS 时优先以其结果核对。
- 用户实测：兼容渲染器错误处理 5R 模板的共享公式，曾把敏捷等属性显示为 10。渲染图仅供布局参考；绝不可把它保存回原卡或以它覆盖 WPS/Excel 的计算值。
- 模板部分隐藏资料页原有失效引用。验卡时分别记录「主卡核心格/公式错误」与「未选选项所在的隐藏资料页错误」。后者若不影响当前角色，不应冒称新填卡错误，也不应擅自修补模板。
- `主要!L40` 是护甲名称输入格，填「链甲」等具体护甲名称正确；不要把它改成「重甲」这样的护甲类别。AC 应继续核对护甲、额外加值和盾牌装备状态。
