# 从人物经历决定技能与分点

玩家委托补全时使用。COC 的分配首先要让数值体现人物：职业、学习、训练、爱好和生活经历决定会什么、擅长到什么程度；实用性用于检查能否参与调查和应对公开情境。不能为了高成功率反过来捏造一段万能训练史。玩家已确定的背景、属性、技能与 KP 要求是约束。

## 先有经历，再有点数

按现有流程先写六项背景和故事，再建立简短对应：**经历或训练 → 具体技能 → 熟练程度 → 所用点池**。用已知事实说明理由，不要求每项都再编一段故事。

- 本职技能体现日常工作和资历。同为医生、记者或学生，也应因专科、工作方式和经历有不同的强弱项；职业允许选择不代表此人受过每一种训练。
- 兴趣技能体现业余爱好、旧职业、家庭影响或具体经历。兴趣点也能补本职；不能把所有兴趣点都当作战斗补丁，或无依据地给普通人多门枪械、开锁与野外生存。
- 开放职业名额仍属于职业点，按职业原文选择与人物经历相关的项目；用开放名额承接真实专长，避免把明确的本职训练全挤到兴趣池里。
- 信用评级结合身份、生活水平、职业范围和可用装备选择；不一律压到下限省点，也不为购买强力装备把人物改成富豪。

故事与技能冲突时，优先保留玩家设定并调整 Agent 代选的技能。若输入本身矛盾或预算无法支持玩家要求，说明具体冲突再确认；不要偷偷改写人生经历。可以保留“不擅长”的地方，人物不必覆盖所有职责。

## 分配预算时看最终值

先核对职业必选/候选/开放名额、职业公式、兴趣池和 KP 上限，再按经历确定相对投入重点。先保障人物最有依据的专长，然后分给次要工作技能和实际爱好；不要平均撒点，也不要把每项都推到上限。

KP 对职业/非职业技能设不同上限时，先按职业条目和合法开放名额分类，再分别约束；兴趣点补本职技能不改变其类别。先确认上限约束最终值还是投入点，数字不明时不套默认值。完整计划用 `skill_limits` 显式记录口径与上限，并给每项技能记录分类依据；最终值口径另提供核对过的基础值，脚本会检查声明的数据是否超限，见[输入格式](input-schema.md#团规的两类技能上限)。

从对应年代规则或模板核对基础值，按“目标最终值 − 基础值”计算投入；最终值由基础、职业点与兴趣点等合法来源构成。不能把投入40点说成技能40。多数 COC 技能不直接随高属性提高；属性影响点池、派生值以及明确关联的基础值，不能照搬 DND 的高属性对应技能思路。

普通、困难、极难检定分别看全值、向下取整半值和五分之一值。可用它们检查数值是否符合叙述中的熟练程度，但不设人人通用的“核心技能必须70”门槛，也不为凑整数牺牲人设。建卡上限及例外依 KP 要求；快速建卡的固定技能数组不能混入当前职业公式＋`INT×2` 的完整建卡流程。

## 再检查调查参与与搭配

从公开导入中找此人自然会做的事，例如查账、访谈、检索资料、看诊、观察现场或操作机器。让他有能主动参与的切入点；不要求每人兼顾侦查、聆听、图书馆、全部交涉和战斗。队友只用已知信息，未知就注明未知；已知有人擅长某项也不构成删除人物本职技能的理由。

检查几种与经历有关的配合即可：资料语言与实际可读资料、专业技能与解释线索、交涉方式与人物性格、武器专攻与实际携带武器、现场行动与工具。不同技能用途独立：心理学不能保证测谎，急救不等于医学，侦查不代替聆听，神秘学不等于克苏鲁神话；不能为拼“联动”承诺替代检定。

再看公开危险是否暴露明显缺口。逃跑、隐蔽、求助或保存证据都可以是应对方式，不强迫普通调查员变成战斗人员。若某项重要能力缺乏训练依据，保留弱项并说明后果或合理的非数值办法；需要补写经历时应与原人设相容，不能用未公开剧情定制克制能力。

## 例子只展示差异

- 同为记者，长期跑社会新闻的人可以侧重访谈、心理学和资料检索；有摄影工作经历的人可以把摄影作为专长。不能因为是记者就两套都堆高。
- 医生的专科与日常诊疗支持医学及相应职业选择；周末驾车出诊可以支持驾驶兴趣。未有用枪经历时，不因模组危险就默认枪法熟练。
- 学生根据专业、社团与家庭经历使用开放职业名额和兴趣点；高 INT 提供预算，不等于自动精通所有学科。公开导入中能认出某类资料即可成为参与理由，无须补齐一整套侦探技能。

## 记录与验收

Agent 代选时在 `build_strategy` 记录人物概念、已知队伍情况、每项投入技能的经历依据，以及少量重要取舍；结构见[输入格式](input-schema.md#分配依据)。交付摘要说明人物拿手的事、一个关键取舍和实际弱点，不把长篇说明塞进卡面。

脚本只检查依据记录与实际投入技能名称一致，并写入报告；它不自动评判故事可信度、计算技能最终值或完整验证职业资格与 KP 上限。Agent 仍须核对基础值、最终值、点池、职业来源及上限，再看故事是否支持这份分配。修改说明不能触发重新掷年龄检定。

参考：[Chaosium职业与技能](https://cthulhuwiki.chaosium.com/investigators/step-three-occupation-and-skills.html)可核对技能用途和职业关联，但其中使用快速建卡法；[七版转换指南](https://www.chaosium.com/content/FreePDFs/CoC%207/CHA23135-Conv%20-%20Call%20of%20Cthulhu%207th%20Edition%20Conversion%20Guidelines.pdf)说明了技能与属性的设计关系。具体职业、点数与技能限制仍按所用完整规则和 KP 要求。
