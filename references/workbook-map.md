# 工作簿映射

模板第一个物理页签是内部计算页 `附表`。用户所说的第一个表应解释为第一个可见主卡 `人物卡`，不得向 `附表` 写人物内容。

## 基础信息与属性

| 内容 | 单元格 |
| --- | --- |
| 姓名、玩家、年龄、时代 | `E3`、`M3`、`E4`、`M4` |
| 职业名称、职业序号 | `E5`、`M5` |
| 性别/性取向、国籍、住地、故乡 | `E6`、`M6`、`E7`、`M7` |
| 当前年份 | `G8` |
| STR / CON / SIZ | `U3` / `U5` / `U7` |
| DEX / APP / INT | `AA3` / `AA5` / `AA7` |
| POW / EDU / Luck | `AG3` / `AG5` / `AG7` |

个人描述、思想与信念、重要之人、意义非凡之地、宝贵之物、特质分别写 `AA61`、`AA63`、`AA65`、`AA67`、`AA69`、`AA71`。背景故事写 `W79`。

技能位于 16–49 行，左栏名称在 F/H，职业点和兴趣点写 N/P；右栏名称在 AB/AD，职业点和兴趣点写 AJ/AL。不要覆盖基础值、总值、半值和五分之一值公式。

职业说明中的开放技能（“任意特长”）还必须把模板技能主名称写入 `BA18:BA22`、`BJ18:BJ19`（依次填充，最多 7 项）。这块不只是展示：卡片用它计数，并据此给对应技能标本职星号。只写职业点 `N/AJ` 不会让右侧槽位自动显示。专精如 `科学①` 应写模板主名称而非自造显示名，以供公式匹配。

随身物品从第 79 行开始，真正随手可取的物品名称写 F 列、部位写 D 列、状态写 B 列；背包或挎包内物品只写 N 列，不在左栏重复写“背包”。每件物品单独占一格，逗号或顿号分隔的清单应拆开。武器第 53 行是模板自带徒手攻击；新增武器使用 54–58 行，名称写 B 列，模板武器键写 G 列，其他属性由公式查表。

脚本通过 OOXML 直接修改以上输入格，并将工作簿计算模式设为自动。不要用普通表格库重建工作簿；模板含大量公式、名称、图表、验证和隐藏页，重建容易丢失功能。
